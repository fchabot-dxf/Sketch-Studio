### Area-by-Area Summary

- **Drag:** Fully-constrained rect corner stays rigid (`nullity: 0, maxMoveAfterDrag: 0` — OK); zero-length collapse recovers cleanly when a 25 mm dim is applied (`lenAfterZeroDrag: 0, lenAfterRecover: 25` — OK); tangent circle dragged across line (`yBefore: 20, yAfter: 20, flippedSide: false` — OK) and tangent circle-circle dragged through center (`branch: "external", distCenter: 30` — OK). **Bugs found:** locked circle rim drags freely (**B-1**), free-R fillet inverts (**B-12a**), arc end past start wraps to 352° (**B-12b**), mirrored Bezier handles freeze (**B-12c**), free mirror line rotates when mirrored line is dragged across (**B-12d**), cluster drag fails to pull to line midpoint during drag (**B-18a**).
- **Dimensions:** Unsolvable edits (negative `-10`, zero `0`, triangle-breaking `200`, self-ref `d1 + 5`, unknown `foo`, mutual cycle `d1 = d2 + 1`) all refuse cleanly with zero geometry drift (`maxMove: 0, histDelta: 0` — OK). Angle edits across 180° (`170 → 190 → 270 → 350 → 360`) solve cleanly and refuse `370`, `0`, `-10` (`reverted: true` — OK). **Bugs found:** `toggleDriving` warps H/V reference dims to Euclidean distance (**B-2**), snaps line-line & point-to-axis reference dims to stale values (**B-3**), pushes no undo (**B-4**); redundant Angle dim born driving (**B-9**); mid-placement tool switch leaks phantom dim (**B-7**); pre-select `D` blocked by H/V or reference dims (**B-13**); double-clicking pattern label in Dimension tool opens `#dimInput` (**B-16**); draw-time box asymmetries (**B-8, B-19**).
- **Constraint Add / Delete:** Deleting a constraint moves nothing (`maxMove: 0` — OK); deleting a mirror line removes its 4 `symmetric` constraints (`symBefore: 4, symAfter: 0` — OK); deleting one source line of an offset removes the offset constraint cleanly (`offCAfterSourceDel: 0, converged: true` — OK). **Bugs found:** `deleteSelection` deletes constraints on a **locked** sketch (**B-5**); pre-selected point + Parallel creates corrupt `parallel(jointId, lineId)` (**B-6**); Midpoint own-endpoint wedges Line tool (**B-10**); Coincident allows Arc's own endpoint onto its own arc (**B-11**); duplicate H/V toast silent on pre-select (**B-14c**); inconsistent invalid-pick tool exit (**B-15**).
- **Status / Undo / Redo:** Over-constrained/locked coloring broken for locked circles (**B-1**) and fixed-endpoint Beziers (**B-20b**); 9 raw `[ERR-*]` / JSON toasts remain (**B-20a**); Lock (`F`), `toggleDriving`, and auto-driven conversion on double-click all omit `saveState()` (**B-4, B-9**).
- **Fillet / Chamfer / Mirror / Pattern / Offset:** **Chamfer** does not exist as a sketch tool in Sketch-Studio (only Fillet; chamfers exist only in Shaper CAM). Rect pattern translates cleanly under source drag (`srcDelta: [10,5], copyDelta: [10,5]` — OK); offset stays un-inverted under drag (`offsetInverted: false` — OK). **Bugs:** free-R fillet inversion (**B-12a**), mirrored Bezier frozen handles (**B-12c**), free mirror line rotation (**B-12d**), pattern label double-click in Dimension tool (**B-16**), fillet/offset boxes reject formulas (**B-19e**).
- **Performance (~200 constrained items, numbers only — `solver-ux-audit-1000b-core.mjs`):**
  - 25 welded rects (100 shapes, 201 joints, 249 constraints): `initSolveMs: 0.6`, `quickDrag8MsAvg: 4.49`, `quickDrag8MsP95: 12.11`, `frameSolve500MsAvg: 1.79`, `frameSolve500MsP95: 3.33`, `jointFreedomMs: 0.85`, `nullity: 25`.

## Divergences from Standard CAD Sketchers (Owner Decides)

These appear deliberate or architectural rather than broken; listed separately so the owner can decide whether to align with Fusion 360:

1. **No Sketch Chamfer tool:** Fusion 360 / SolidWorks / Onshape offer Sketch Chamfer alongside Sketch Fillet `(unverified)`. Sketch-Studio has only Sketch Fillet (chamfers live in Shaper CAM).
2. **Mirror / Pattern / Offset under MODIFY instead of CREATE:** Fusion places Mirror, Circular/Rectangular Pattern under CREATE (`docs/FUSION-COMPARISON.md`). Sketch-Studio groups them under MODIFY.
3. **Redundant geometric constraints & solver policy:** Fusion refuses a redundant geometric constraint (e.g. Vertical on an already-constrained vertical line) with an over-constrained alert `(unverified)`; Sketch-Studio's `ConstraintManager` rejects exact duplicates (`source === 'toolbar'`) but tolerates some algebraically redundant combinations in the LM solver.
4. **Bezier handles as unconstrained shape data:** Fusion's control-point splines expose control polygon points as constrainable/dimensionable sketch points `(unverified)`; Sketch-Studio stores Bezier `c1`/`c2` as plain shape fields (only endpoints are solver joints — see **B-12c**, **B-20b** for the UX leaks this causes).
5. **Draw-time Line angle & Arc sweep not turned into persistent constraints (B-19d):** In Fusion, typing a draw-time angle in Line creates a driving angle dimension `(unverified)`; Sketch-Studio currently treats draw-time angle/sweep as construction guidance only (only length/radius creates a dimension).
6. **Angle dimension accepts 360° (`4b`) and rejects 0°:** Fusion caps sketch angle dimensions below 360° or wraps modulo 360° `(unverified)`; Sketch-Studio allows `(0, 360]` and rejects `<= 0` and `> 360`.
